API Keys

Generate a key, then use it from any CLI: Authorization: Bearer <key>

CLI example (OpenCode): set baseURL to https://your-app.vercel.app/api and apiKey to one of the keys above. For Codex, point base_url at https://your-app.vercel.app/v1 — note Codex expects the Responses API; this proxy serves both /api/chat and /api/responses.
